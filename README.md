# Bikash Sahu

Personal site: work, experiments and notes.

```bash
npm run dev   # http://localhost:3000
npm run build
npm start
```

Built with Next.js (App Router) and Tailwind CSS. The social card is generated at
build time by `app/opengraph-image.tsx` (`next/og`), and `app/twitter-image.tsx`
reuses the same design.
